# Konnex

Instaladores do Konnex para Windows e Mac.

A atualização é oferecida dentro do próprio programa. Se você chegou aqui por outro caminho, baixe a versão mais nova em **Releases**:

- **Windows:** `Konnex-Setup-<versão>.exe`
- **Mac com chip Apple (M1 ou mais novo):** `Konnex-<versão>-arm64.dmg`
- **Mac com Intel:** `Konnex-<versão>-x64.dmg`

Site: https://konnexgestao.com.br
